\section{Demonstration}
\label{sec:demo}

The conference demonstration compresses the course's usage pattern into ten
minutes: visitors watch the full lifecycle execute in thirty seconds, read a
module whose displayed code is drift-guarded, solve an exercise live and watch
it graded against the maintained implementation, and then perturb the system
(halving \texttt{kv\_lora\_rank}; renaming a library function to trip the
guards; submitting concurrent requests to the batching server). Because the
target platform is the machine many attendees carry, the session doubles as an
install-fest: visitors can reproduce every step on their own devices. The
complete walkthrough, with a session transcript, is given in
Appendix~\ref{app:demo}.

\paragraph{Availability.} Code, courseware, experiments, and CI are public
under the MIT license at \url{https://github.com/jc-su/BabyWhale}; the
rendered course is served at \url{https://jc-su.github.io/BabyWhale}.
Requirements: an Apple-Silicon Mac (MLX) and Python 3.14. Every demonstration
step above also runs in the project's CI.
