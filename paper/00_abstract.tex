\begin{abstract}
Education about large language models is fragmented: existing resources teach
pre-training, alignment, or serving in isolation, on codebases that do not
compose, and their explanatory prose is checked by no one. We present
\textbf{BabyWhale}, an open educational system organized around two ideas.
First, \emph{the curriculum is one model's biography}: a single checkpoint is
carried through architecture, pre-training, mid-training, supervised and
preference fine-tuning, reinforcement learning with verifiable rewards,
quantization, and serving, on a $\sim$15.8K-line DeepSeek-style stack built on
MLX---a platform we argue is pedagogically apt (readable pure-Python modeling,
unified memory) and communally impactful (the Apple-Silicon install base and
its ecosystem of community-converted models). Second, \emph{the courseware is
machine-checked}: build exercises are graded by functional equivalence against
the maintained implementation, quantitative claims are regenerated by committed
scripts, and displayed code is guarded by tests that fail when documentation
drifts from source. These guards are motivated empirically---an audit of our
own early drafts found eight confidently wrong explanations---and the released
system carries 334 continuously run tests, including the courseware checks
themselves.
\end{abstract}
