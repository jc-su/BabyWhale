\section{Every Claim Is a Command}
\label{sec:measured}

A recurring failure of educational material is the unmeasured claim (``MLA
saves memory''). In BabyWhale each module's payoff beat is a runnable script;
the figures below are plotted from the \emph{same numbers those scripts
print}, so a reader can reproduce every curve with one command.

\paragraph{Analytic ablations.} Figure~\ref{fig:ablations} shows two of the
six: attention cost scaling and the KV-cache decode saving. The others print
the MLA cache footprint (MHA $2048$\,B vs.\ MLA $256$\,B per token per layer
at 8 heads $\times$ 128 dims, bf16: $8\times$ smaller at MQA size), MoE's
decoupling ($8\times$ parameters at $2\times$ FLOPs for 8 experts, top-2),
expected speculative tokens per verify pass ($4.1\times$ at draft-acceptance
$p{=}0.9$, $k{=}4$), and bf16$\to$FP4 weight memory ($4\times$).

\paragraph{The preset ladder, trained.} Beyond analytic ablations, the paper
ships a one-command experiment script
(\texttt{paper/experiments/run\_experiments.py}) that regenerates every
measured number below on the reader's own machine. Table~\ref{tab:ladder}
trains all six presets of the course's motivation ladder under identical
conditions: the architecture features cost parameters and decode-relevant
structure while leaving toy-scale LM loss essentially unchanged---evidence
for the course's framing that their value must be (and is) measured in
capabilities and serving rather than perplexity. The same script measures
cohort batching end-to-end on the laptop: aggregate decode throughput rises
from 316 to 546, 810, and 1{,}389 tok/s for cohorts of 1, 2, 4, and 8
($4.4\times$)---the number Module~17's ``payoff'' beat promises.

\paragraph{A real end-to-end run.} Figure~\ref{fig:loss} shows the course's
reference pre-training run, produced by the repository's own CLI on consumer
hardware. Laptop-scale matters pedagogically: every stage of the lifecycle,
including the RL loop and the batching server, completes in classroom time,
so ``break it and re-run'' is a five-minute experiment rather than a cluster
job. The fast byte-BPE encoder this run depends on is itself a course story:
the naive encoder stalls on long lines, while the heap-based one packs the
15.2M-token corpus in 52\,s---and the corresponding lab requires the
learner's simple encoder to match it token-for-token.

\paragraph{How the system was evaluated.} Three ways, all mechanical and
reproducible. \emph{(i) Artifact verification:} 334 tests run green in public
CI on Apple-Silicon runners, including one grader per lab (each proven to
accept the reference solution \emph{and} reject a representative wrong one),
two milestones that train real models inside the suite, the drift and
coverage guards, and a strict documentation build; the course site redeploys
on every push. \emph{(ii) A quantified content audit:} we line-audited all 20
theory-to-code bridges against the implementation and found \textbf{8
inaccuracies}, taxonomized in Table~\ref{tab:audit}---all corrected, and the
error classes directly shaped the integrity mechanisms. \emph{(iii)
Reproducibility:} CI performs a from-scratch environment sync and full run on
every commit, i.e., a continuous clean-machine installation test. We have not
yet run a controlled human learning study; this is the main open evaluation
(\S\emph{Limitations}).
